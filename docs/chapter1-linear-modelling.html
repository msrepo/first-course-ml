The least-squares solution minimises L. Setting ∂L/∂w0 = 0 and ∂L/∂w1 = 0 gives w1 = (mean(xt) − mean(x)·mean(t)) / (mean(x²) − mean(x)²) and w0 = mean(t) − w1·(mean(x) − c). The slope w1 is the same whichever c you pick.
