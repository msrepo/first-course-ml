Chapter 4 · Each object has two attributes, x1 and x2, and a binary label t. The aim is to learn a rule that predicts t for a new object. Hover or tap a point to read its values. Data: logregdata.mat from the book's companion files.

Hover over a point.

The two classes occupy different regions of the plane, with a gap between them. There is no response variable on a continuous scale, only a class label, so this is a classification problem rather than regression. In the chapter, a linear score wTx passed through the sigmoid turns this into the probability that a point belongs to class 1.
