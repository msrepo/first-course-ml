log g(w) = log-likelihood + log prior: the log of the unnormalised posterior, which the MAP fit maximises. Accuracy classifies a point as t = 1 when P > 0.5.

A weight vector w defines the boundary wᵀx = 0, a line through the origin. Scaling w by a constant does not move this line, only how sharply the probability changes across it, so σ² controls the confidence of the draws but not their directions. A large σ² gives draws with extreme probabilities, most of which fit the data poorly. The MAP weights are found by Newton–Raphson on log g, which has a single maximum.
